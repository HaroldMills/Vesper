Create dataset call clips

Creates dataset call clips from the specified clips.

{% include "vesper/clips-specification-message.html" %}

This command creates one dataset call clip for each of the specified clips that has both Call Start Time and Call End Time annotations. Calls are centered within the new clips.

The command marks the clips it creates as having been created by the processor Dataset Call Clip Creator 1.0. It creates the processor in the archive database if needed.

The command copies all annotations and tags of the original clips to the new clips.

The command adds an Original Clip ID annotation to each new clip. The value of the annotation is the database ID of the original clip from which the new clip was created. The command creates an Original Clip ID annotation info object in the archive database if needed.

The command also tags each clip it creates with Dataset New. It creates a Dataset New tag info object in the archive database if needed.

Specify the dataset call clip duration in seconds in the Clip duration field.
